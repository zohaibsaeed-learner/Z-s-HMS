Put the brand font files here, with exactly these names (.woff2 or .otf both work):

  MonumentExtended-Ultrabold.otf   (dashboard name)
  MonumentExtended-Regular.otf
  Telegraf-UltraBold.otf           (headings)
  Telegraf-Regular.otf

Both families are free for personal use from Pangram Pangram (pangrampangram.com).
Until the files are here, the app falls back to Unbounded (name) and Hanken Grotesk (headings).
Body text uses Aptos if it is installed on the computer, otherwise Roboto.
